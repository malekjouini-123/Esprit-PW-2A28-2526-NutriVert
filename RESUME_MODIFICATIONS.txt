🔐 FLUX DE NAVIGATION FINAL
================================================================================

1. VISITEUR (non connecté)
   index.php
   └→ interface.php (page accueil)
      ├→ Clic "Connexion" → index.php?view=login
      └→ Clic "Inscription" → index.php?view=register

2. INSCRIPTION (Utilisateur)
   index.php?view=register
   └→ POST /controllers/UserController::register()
      ├→ Validation données
      ├→ Hashage mot de passe (bcrypt)
      ├→ Calcul IMC/calories
      └→ Redirection → index.php?view=login

3. CONNEXION
   index.php?view=login
   └→ POST /controllers/UserController::login()
      ├→ Recherche utilisateur
      ├→ Vérification mot de passe
      ├→ Création session
      └→ Redirection selon rôle:
         ├─ user   → index.php?view=interface
         ├─ coach  → index.php?controller=coaching&action=index
         └─ admin  → index.php?controller=dashboard&action=index

4. UTILISATEUR CONNECTÉ (role = 'user')
   index.php?view=interface
   └→ Voir les programmes de coaching
   └→ Voir profil (poids, taille, IMC, calories)
   └→ Déconnexion

5. COACH CONNECTÉ (role = 'coach')
   index.php?controller=coaching&action=index
   └→ Voir ses programmes
   ├→ Créer nouveau programme
   ├→ Modifier programme
   ├→ Exporter en PDF
   ├→ Générer séance
   ├→ Gérer exercices
   └→ Bouton Back-office visible si role === 'admin' aussi

6. ADMIN CONNECTÉ (role = 'admin')
   index.php?controller=dashboard&action=index
   └→ Tableau de bord complet
   ├→ Gérer tous les programmes
   ├→ Gérer tous les exercices
   ├→ Voir statistiques
   └→ Retour au site (view=coaching)

7. DÉCONNEXION
   index.php?controller=user&action=logout
   └→ Destruction session
   └→ Redirection → index.php
